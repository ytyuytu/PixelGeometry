# PixelGeometry

A computer graphics project written in C.

## Features

- **Bresenham's Line Algorithm** — line rasterization in all eight octants.
- **DDA Algorithm** — alternative line rasterization.
- **Flood Fill** — area filling using a stack with 4- and 8-connectivity.
- **Scanline Fill** — polygon filling using the scanline algorithm.
- **Statistics** — pixel and step counting.
- **PGM Export** — saving the resulting image to a file.

## Technologies

- C
- GCC
- Makefile

## Build and Run

```bash
make
./program
```
